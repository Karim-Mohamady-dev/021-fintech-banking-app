# Lumen Bank — 021-fintech-banking-app

صفحة هبوط لتطبيق مصرفي: إدارة حساب ورؤى إنفاق وبطاقات وتحويلات وأدوات مالية، مع لوحة مصرفية تفاعلية.

## التشغيل

```bash
npm install
npm run dev
npm run build
```

## البنية

- `src/App.tsx` — أقسام الصفحة: تنقل، بطل، مزايا، كيف يعمل، إثبات، أسعار، أسئلة شائعة، دعوة أخيرة، تذييل.
- `src/Demo.tsx` — العرض التفاعلي في قسم البطل (بيانات نموذجية موسومة).
- `src/i18n.tsx` — التبديل بين العربية والإنجليزية وحفظ التفضيل في localStorage.
- `locales/en/common.json` و`locales/ar/common.json` — كل النصوص. لا نصوص مكتوبة داخل المكونات.
- `src/index.css` — نظام التصميم: الخط، الألوان، مقاسات النص، حركة cubic-bezier(0.22,1,0.36,1).

## ملاحظات

- كل الأرقام والأسعار والشهادات نموذجية وموسومة، والأسعار الحقيقية تظهر كـ `{{price}}`.
- نموذج التسجيل يتحقق من الاسم والبريد ويحفظ محليا في المتصفح فقط.
- الصفحة متجاوبة من 320px إلى 1440px فأكثر، وتدعم تقليل الحركة عبر `prefers-reduced-motion`.
